# Transcript layout studies

Open [index.html](index.html), or serve this directory on `127.0.0.1:4327` with `python3 -m http.server 4327 --bind 127.0.0.1`.

These are three layouts of the same static conversation. Their top light strip is the preview switcher, not part of the proposed app. The examples do not call Pi, change files, or save settings. Tool disclosures and page links work.

| | Sidebar | Header | Main body |
| --- | --- | --- | --- |
| A | Conventional project and session list | Title, path, model and status | Loose messages with a role gutter |
| B | Directory-style session tree | Single command-like line | Compact turn sequence |
| C | Small persistent navigation rail | Minimal project and session line | Wide reading column |

All three keep the prompt exchange primary and tool evidence inline. Skills and settings are destinations, not simultaneous panels. The paths, session, tool results, and model shown are sample content. [Pi Dashboard ethos](../docs/ethos.md) remains the product guide.
